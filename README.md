# 📊 TheLook eCommerce Analytics & BI Project

**Sprint One: Instant** ⚡

A comprehensive Business Intelligence and Analytics project analyzing **TheLook eCommerce** dataset using **Excel Power Pivot, DAX, and ETS Forecasting**.

---

## 📌 Project Overview
This project focuses on evaluating business performance across key operational areas:
* **Financial Performance:** Gross vs. Net Sales, Profit Margins, and regional revenue drivers.
* **Marketing Funnel:** Tracking user journey from sessions to cart additions and final purchases to identify drop-off points.
* **Supply Chain & Inventory:** Analyzing overstocked inventory value and category-level return rates.
* **Predictive Analytics:** Forecasting future sales recovery using Exponential Triple Smoothing (ETS).

---

## 🛠️ Tools & Technologies
* **Excel Power Pivot:** Star/Snowflake Data Modeling.
* **DAX (Data Analysis Expressions):** 17+ measures for financial, web conversion, retention, and supply chain metrics.
* **Excel Forecast ETS:** 95% Confidence interval time-series forecasting.
* **Documentation:** Executive PDF Report & Data Dictionary.

---

## 📁 Repository Contents
* `TheLook_eCommerce_Dashboard.xlsx`: Full Excel workbook with Power Pivot model and dashboards.
* `thelook_executive_report.pdf`: 3-Page Executive C-Suite Report.

---

## 💡 Key Findings
1. **Financials:** High profitability with a ~51.9% profit margin, driven by top markets (China, US, Brazil).
2. **Checkout Bottleneck:** High add-to-cart rates (~63.4%) contrast with a ~57.9% cart abandonment rate.
3. **Inventory Friction:** Over $8.8M locked in unsold inventory, mainly concentrated in Jeans and Outerwear.
